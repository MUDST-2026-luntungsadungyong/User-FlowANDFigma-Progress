📋 รายงานข้อขัดแย้งและการแก้ไข User Flow vs Figma UI

วิเคราะห์เปรียบเทียบจุดบกพร่องของ Flow เดิม (Before) กับแนวทางแก้ไขที่สอดคล้องกับ Figma 100% (After)

⬇️ ดาวน์โหลด SVG 📄 เปิดรายงาน Markdown
📊 แผนผังเปรียบเทียบความขัดแย้งและการแก้ไขทั้งหมด (Vector Swimlane)
💳 1. ข้อขัดแย้งในระบบ Checkout (US-04)

ใน Flow เดิมข้ามขั้นตอนสำคัญก่อนจ่ายเงิน ทำให้ API สร้างคำสั่งซื้อขาดข้อมูลที่อยู่จัดส่งและวิธีส่ง

❌ Flow เดิมใน PDF
1. ตะกร้าสินค้า ➔ 2. ข้ามไปจ่ายเงินทันที ➔ 3. สร้าง QR พร้อมเพย์

⚠️ ไม่มีขั้นตอนเลือกที่อยู่จัดส่ง และไม่มีให้เลือกวิธีจัดส่ง

✅ แก้ไขตาม Figma 100%
1. ตะกร้า ➔ 2. เลือกที่อยู่ (Address Book) ➔ 3. เลือกวิธีส่งเข้า Hub ➔ 4. เลือกวิธีจ่ายเงิน ➔ 5. จ่ายเงินเข้า Escrow

✨ สอดคล้องกับ Figma `Checkout Flow/frame_1` ถึง `frame_6` ครบถ้วน

🚚 2. ข้อขัดแย้งในการจัดส่งและตรวจสภาพการ์ด (US-07 vs QC Hub)

Flow เดิมมองเป็นการจัดส่งจังหวะเดียว (Single-Leg Monolithic) แต่ใน Figma เป็น 2-Leg Shipping พร้อมขั้นตอนตรวจสภาพ QC

❌ Flow เดิมใน PDF
Admin ดูออเดอร์ ➔ กดจัดส่ง + ใส่เลข Track ➔ สถานะ Fulfilled

⚠️ ไม่มีขั้นตอนตรวจสภาพการ์ด (QC) ไม่มีการตรวจแท้/ปลอม

✅ แก้ไขเป็น 2-Leg + QC Hub
1. Seller ส่งเข้า Hub (Leg 1) ➔ 2. Hub ตรวจ QC (Pass/Fail) ➔ 3. Hub ส่งหา Buyer (Leg 2) ➔ 4. Buyer รับ ➔ ปล่อย Escrow

✨ สอดคล้องกับ `seller/frame_6` (Leg 1) และ `platform-admin/frame_4` (QC Decision)

🔑 3. ข้อขัดแย้งในระบบสมัครสมาชิก (US-01)
❌ Flow เดิม

ฟอร์มกรอกแค่ 2 ฟิลด์: Username และ Password (ไม่มี Email)

✅ แก้ไขตาม Figma

ฟอร์มมี 3 ฟิลด์: Username, Email, Password (ตรงกับ auth/frame_2)

+ เพิ่ม Sub-flow ลืมรหัสผ่าน (Forgot Password) ตาม auth/frame_3-6

📦 4. ข้อขัดแย้งในการลงขายการ์ด (US-05-1)
❌ Flow เดิม

ให้ร้านค้าพิมพ์ชื่อการ์ดและชื่อเกมเองแบบ Text ธรรมดา

✅ แก้ไขตาม Figma

ค้นหาจาก Master Card Catalog ➔ เลือกระดับสภาพ (Mint/NM/LP) ➔ ถ่ายรูปยืนยันสภาพจริง (ตรงกับ seller/frame_3)

🏪 5. ข้อขัดแย้งในระบบตะกร้าและสต็อกการ์ด (US-02, US-03)
❌ Flow เดิม

มองว่าการ์ด 1 ใบมีสต็อกรวมก้อนเดียว และแจ้ง Error ทันทีบนหน้าสินค้า

✅ แก้ไขตาม Figma

การ์ดใบเดียวกันมีหลายร้านค้าลงขาย (Multi-Seller Listing) ในสภาพและราคาต่างกัน เมื่อกดสั่งซื้อจะเปิด Cart Drawer (Shop & Browse/frame_6)

✨ 6. ฟีเจอร์ที่มีใน Figma แต่ตกหล่นไม่มีใน Flow เลย
1. Seller Wallet & Payout (`seller/frame_9-11`)

ระบบกระเป๋าเงินร้านค้า ดูเงินที่ถอนได้ vs เงินที่ล็อกใน Escrow และส่งคำขอถอนเงินเข้าบัญชีธนาคาร

2. Bulk CSV Upload (`seller/frame_8`)

ระบบนำเข้าสต็อกการ์ดจำนวนมากผ่านไฟล์ CSV Template

3. Dispute & Claims Resolution (`platform-admin/frame_7`)

ศูนย์จัดการข้อพิพาทเมื่อการ์ดไม่ตรงปกหรือชำรุด โดย Super Admin เป็นผู้พิจารณาหลักฐานและสั่ง Refund

4. Forgot Password Flow (`auth/frame_3-6`)

กระบวนการขอรีเซ็ตรหัสผ่านทาง Email Verification Token และตั้งรหัสผ่านใหม่
